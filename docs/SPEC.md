# 仕様（MVP）
## ループ
1か月ごと（国家モードは2か月）に日付が進み、①史実ニュース（号外）②恋愛・家族・手紙イベント ③職業/兵科イベント ④回想（過去の選択の帰結）のいずれかを提示。選択肢はトーン色分け、🎲＝能力判定、☠＝死亡リスク。結果シートに成功/失敗と数値変化。
## 状態
体力・気力・絆・良心・所持金（一般/軍人）、兵員・士気・補給・練度・疲労・信頼（指揮官）、内閣・陸軍・海軍・重臣・枢密院・議会・世論・国際・経済・戦火（国家）。フラグ、NPC（恋人/配偶者・子・兄弟・友人・親）、形見、遅延イベントキュー。
## 決定論
mulberry32 系 seed。同一 seed＋同一選択で同一人生（vitest で検証）。イベント抽選は重み×(既出なら0.35)×(恋愛家族1.4)、クールダウン付き。
## 史実/改変
`hist` レコードは `史実`（出典必須）か `改変`（原因必須）。改変は国家モードの決定でのみ分岐（例：早期和平）。年表パネルで史実と自分の世界を並べて比較。
## 死と継承
死因に応じた訃報と後日談（遺族の台詞）→ 継承者選択（配偶者・子・兄弟・友人。誰も残っていなければ1度だけ「遠縁のいとこ」）。家族などが生き残った物語の後日談（葬儀、戦友の手紙、1945年の空襲と8月15日、1946年の恩給停止、1952年の援護法、遺骨収集、新憲法）を表示。継承時は、死者の戦場の連鎖イベント（mil専用）をキューから除く。継承時は恋愛フラグをリセット。
## セーブ
localStorage `kiro10.save`（version付き、migrate()で旧版変換、未来版/他アプリは拒否）。ファイル/テキストでエクスポート・インポート。
## メディア
`public/media/manifest.json`：各アセットに tags / license / source / label。AVIF→WebPの`<picture>`、lazy loading。動画は1MB未満（ビルド時に強制）。実写（PD/明示ライセンス）を優先し、場面ごとの割り当ては `scripts/assign-media.mjs` → `content/media-assign.json` を `content/build.mjs` が適用する（イベントに img/clip の明示があればそちらが優先）。ニュースカードは手作業で地名・出来事が一致するものだけに画像/映像を付け、それ以外は画像なし（またはAI再現表示付き）。ニュース映画クリップを前線イベントに自動で付けるのは、イベントのタグ・art が一致したときだけ。AI再現は必ず画面に表示する。
## 既知の範囲外
指揮官モードは戦術を抽象化（作戦の詳細シミュレーションはしない）。音声は効果音のみ。
## プレイ時間
目標は1プレイ60分以上（どのモード・開始・早死にでも）。`scripts/playtime.ts` で厳しめに計測：表示文字数÷500字/分＋選択1回5秒。630プレイの結果（中央値／最短）：一般 70.1/61.8、軍人 72.2/60.8、指揮官 72.0/65.1、国家 71.8/62.8（分）。
## 季節場面（暦DSL）
`content/almanac-lib.mjs`。`@日付|題|史実/架空/改変|出典|not=…;flags=…;branch=…` で、`--` で区切った3〜4段の場面を書く。日付窓はモードの1ステップ以上（国家3か月、他2か月）。層は一般（ac, ad）、軍人・指揮官（am, an 海軍, aw 陸軍, al 故郷の便り）、国家（as, at, au, av）。人物の台詞は創作で（創作）と明記し、実在人物の内心は描かない。
## メディア変換
`scripts/convert-media.py`：Pillow で ICC・EXIF を除いてから、ffmpeg で WebP/AVIF に変換（-map_metadata -1）。出力に ICC が残っていれば失敗する。
